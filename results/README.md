# Results

Results produced by clean experiment code belong here.

- Save machine-readable CSV, JSON, NPZ, or similar outputs.
- Preserve the configuration and random seed with every run.
- Do not manually fabricate result files from prose summaries.
- Ignore large or generated artifacts when appropriate.
- Keep the initial reported numbers in [`project/EXPERIMENTS.md`](../project/EXPERIMENTS.md) until clean code reproduces them.
