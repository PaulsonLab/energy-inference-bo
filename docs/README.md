# Documentation map

- [Architecture](ARCHITECTURE.md): source, experiment, test, and result locations.
- [Current research roadmap](research/ROADMAP.md): completed evidence, the active gate,
  and the conditional next stage.
- [Research status](research/PROJECT_STATUS.md): short compatibility pointer to the
  roadmap.

  context.
- [Task registry](../tasks/README.md): canonical specifications, mathematics, summaries,
  and Colab procedures.

Reviewed task figures belong beside their evidence under `results/<task>/<profile>/`;
general architecture or communication assets may live in `docs/`.
