# 1. Scientific Objective

## Working paper title

**Bayesian Optimization as Compositional Free-Energy Inference**

## Organizing thesis

> **Bayesian optimization can be formulated as inference over high-utility worlds, providing a common interface for composing experimental beliefs, pretrained structure, auxiliary information, and future adaptive decisions at test time; standard GP–EI is the quadratic, one-step special case.**

This is the organizing perspective, **not sufficient novelty by itself**.

The eventual paper must demonstrate a concrete capability that becomes meaningfully better or easier under this view.

## Leading capability hypothesis

The current leading hypothesis is:

> A compositional energy/free-energy formulation lets us combine a credible structured belief, pretrained design structure, and adaptive future utility without fitting a new monolithic normalized model, and path-space inference can exploit non-myopic opportunities that remain useful after the belief model is strengthened.

This hypothesis is explicitly falsifiable through the gates below.

# 2. Mathematical Spine

These statements should be treated as fixed unless an actual mathematical error is found.

## 2.1 Belief energy

\[
p_B(f\mid D)
\propto
\exp[-E_B(f;D)].
\]

A GP is one valid special case, not a required assumption.

## 2.2 Structured design factor

If design structure is genuinely part of the decision model,

\[
p_G(x)
\propto
\exp[-E_G(x)].
\]

A crucial distinction:

### Semantic prior

If

\[
\Pi(x)\propto p_G(x)\alpha(x),
\]

then \(p_G\) changes the decision criterion.

### Proposal only

If a pretrained generator is only used to propose structured candidates, it must not silently alter the BO objective.

This distinction must remain explicit throughout the project.

## 2.3 Auxiliary information

For valid information \(C_j\),

\[
L_j(C_j\mid f,x)
=
\exp[-E_j(f,x)].
\]

Prefer probabilistic/likelihood semantics.

Avoid arbitrary energy coefficients.

## 2.4 Decision utility

For nonnegative utility,

\[
U_x(f)
=
\exp[-E_U(x,f)].
\]

The one-step compositional target is

\[
\Pi(x,f\mid D)
\propto
p_G(x)
p_B(f\mid D)
\prod_j L_j(C_j\mid f,x)
U_x(f).
\]

Marginalizing \(f\),

\[
\Pi(x\mid D)
\propto
p_G(x)
\mathbb E_{p_B}
\left[
U_x(f)\prod_j L_j(C_j\mid f,x)
\right].
\]

With uniform \(p_G\) and no auxiliary information,

\[
\Pi(x\mid D)
\propto
\alpha(x).
\]

For a GP belief and improvement utility,

\[
\Pi(x\mid D)
\propto
EI(x).
\]

Equivalently,

\[
\log\alpha(x)
=
F_B-F_{B+U}(x).
\]

## 2.5 Belief error versus decision-inference error

Let

\[
V_H^\star(x)
\]

be the true horizon-\(H\) value,

\[
V_H^B(x)
\]

the value under the current belief model, and

\[
\widetilde V_H^B(x)
\]

the value computed by approximate decision inference.

If

\[
\sup_x
|V_H^\star(x)-V_H^B(x)|
\le \epsilon_B
\]

and

\[
\sup_x
|V_H^B(x)-\widetilde V_H^B(x)|
\le \epsilon_I,
\]

then for the selected action \(\hat x\),

\[
\boxed{
V_H^\star(x^\star)
-
V_H^\star(\hat x)
\le
2(\epsilon_B+\epsilon_I).
}
\]

Interpretation:

- better belief models reduce \(\epsilon_B\);
- better planning/inference reduces \(\epsilon_I\);
- sophisticated planning cannot rescue a badly misspecified belief;
- the strongest result occurs if belief quality and decision inference are complementary.

## 2.6 Factor sensitivity

For

\[
p_\lambda(f)
\propto
\exp[-E_0(f)-\lambda E_C(f)],
\]

\[
\frac{\partial}{\partial\lambda}
\log\alpha_\lambda(x)
=
\mathbb E_{p_\lambda}[E_C]
-
\mathbb E_{p_{\lambda,U,x}}[E_C].
\]

Interpretation:

> **A factor matters to BO when it preferentially reweights high-utility worlds.**

Treat this as a conceptual/factor-attribution identity, not as the main algorithm.

# 3. Research Principles

1. **Energy must be operationally useful.** A change of notation is not enough.
2. Do not pursue another generic “EBM is a more flexible surrogate” experiment.
3. Use strong conventional probabilistic beliefs when appropriate.
4. Exploit pretrained structure rather than trying to relearn it from tiny BO datasets.
5. Reuse established EBM/diffusion/SMC machinery before inventing a sampler.
6. Do not introduce arbitrary energy weights without statistical or decision semantics.
7. **Decision quality is primary.** Density fit, ESS, wall-clock, and sampler quality are diagnostics.
8. At least one headline result must use actual measured labels rather than only a learned proxy oracle.
9. Every gate must have a prospective GO/NO-GO rule.
10. No individual GPU shard should require more than approximately 2–3 hours on one A100.
11. Every task must have a local smoke test suitable for a 16 GB MacBook Air.
12. Negative results are legitimate outcomes.
13. Do not advance because a result is interesting. Advance only because the gate passes.

# 8. Task 05A — Structured Belief Gate

## Question

> In structured low-data protein design, is there a credible probabilistic belief model, and does stronger structure materially improve BO-relevant decisions?

This task does **not** require the sophisticated model to win.

The critical failure condition is that none of the candidate beliefs is trustworthy enough to support downstream decision experiments.

## Data

Initial primary datasets:

- measured TrpB variants;
- measured CreiLOV variants.

Use actual experimental labels.

Do not use a learned proxy oracle for the primary 05A result.

## Model ladder

Required:

### S0 — Generic baseline

A simple sequence GP using a standard generic representation/kernel.

### S1 — Lightweight structured GP

BLOSUM/Tanimoto or similarly simple biologically structured kernel.

### S2 — Strong structured GP

LOCK-GP, or the closest faithful and practical public implementation.

Optional only if inexpensive:

### S3 — Pretrained representation + Bayesian head

For example, fixed pretrained protein features followed by a simple GP or Bayesian linear model.

Do not train a neural EBM in Task 05A.

---

## 05A.1 Offline evaluation

Training sizes:

\[
n\in\{48,96,192\}.
\]

Use 10 frozen splits shared by all methods.

Required metrics:

- NLL and/or CRPS;
- RMSE;
- Spearman correlation;
- top-10% rank recall;
- calibration in the high-predicted-utility region;
- finite-pool one-step BO decision regret;
- probability that the selected candidate lies in the true top decile.

BO-relevant decision metrics matter more than overall RMSE.

---

## 05A.2 Sequential measured-pool BO

Default full protocol:

- \(n_0=48\) initial observations;
- 32 sequential evaluations;
- 10 paired seeds;
- identical initial observations across methods;
- LogEI acquisition;
- candidates = unobserved measured sequences.

Primary trajectory:

\[
R_t
=
\frac{f_{\max}-f_t^\star}
{f_{\max}-f_0^\star}.
\]

Report:

- AUC of normalized simple regret;
- final normalized regret;
- probability of discovering a top-1% sequence;
- probability of discovering a top-5% sequence.

---

## Gate 05A

### PASS-A — Structured gain

Pass if a structured model is credibly calibrated and gives, on at least one primary dataset, either:

- at least **20% relative reduction** in BO decision regret; or
- at least **+15 percentage points** in a predefined top-tail hit probability,

with no catastrophic calibration failure or severe regression on the second dataset.

Use the best credible structured belief downstream.

### PASS-B — Baseline sufficient

Also pass if S0 is already credibly calibrated in the BO-relevant region and structured models do not materially improve decision quality.

Interpretation:

> belief quality is not the dominant bottleneck on this benchmark.

Use the simplest credible belief downstream.

### FAIL

Fail if none of the tested models produces a credible probabilistic belief in the BO-relevant region.

Then:

- do not implement 05B;
- set `HUMAN_REVIEW_REQUIRED`;
- summarize the failure;
- propose at most one narrow belief-model rescue experiment for human approval.

# 9. Task 05B — Structured Composition Gate

## Authorization

Requires:

```text
05A = PASS
```

## Question

> Can the credible Bayesian belief from 05A be combined with a pretrained structured generator and Bayesian utility at inference time without training a new monolithic model or relying on retrospective energy-weight tuning?

## Initial system

Use one public pretrained protein generator/checkpoint from an existing system such as SGPO, initially on the easiest reproducible protein task.

Do not pretrain a foundation model.

## Keep two modes separate

### Proposal-only mode

\[
x\sim p_G
\]

proposes structured candidates, but the BO decision remains

\[
\arg\max_x\alpha_D(x).
\]

### Semantic design-prior mode

Only if naturalness/prior probability is genuinely part of the scientific objective:

\[
\Pi_D(x)
\propto
p_G(x)\alpha_D(x).
\]

This is a different decision criterion and must be labeled as such.

## Required baselines

Start simple:

1. unconditional generator samples + LogEI ranking;
2. published/default existing guidance;
3. posterior-mean guidance;
4. Thompson-style guidance where available;
5. expected-utility/free-energy guidance only if it can reuse existing machinery cleanly.

Do not implement a sophisticated sampler before checking sample-and-rank.

## Diagnostics

Record:

- best acquisition versus generator calls;
- unique candidates / duplicate rate;
- validity / feasibility;
- importance-weight ESS where relevant;
- runtime;
- sensitivity to guidance strength;
- whether different inference mechanisms actually change the selected query.

## Gate 05B

### PASS

Pass if at least one existing inference route can implement the intended target reproducibly, within compute budget, without tuning hyperparameters against final BO outcomes.

**Simple sample-and-rank is allowed to pass.**

05B is primarily a feasibility/generality gate, not the main novelty result.

### FAIL

Fail if:

- public pretrained inference cannot be reproduced within budget;
- arbitrary outcome-dependent guidance tuning is necessary;
- important modes cannot be represented;
- proposal versus target semantics cannot be made clean.

Then request human review.

# 10. Task 05C — Surrogate × Planning Gate

## Authorization

Requires:

```text
05B = PASS
```

## Question

> Does non-myopic planning still improve actual BO decisions after strengthening the belief model?

This question must be answered **before** building a new path-space planner.

## Factorial design

Use:

- S0 = generic belief;
- S* = strongest credible belief from 05A.

Compare:

- \(H=1\);
- \(H>1\), initially \(H=2\) or \(H=3\).

Thus:

\[
\begin{array}{c|cc}
& H=1 & H>1\\
\hline
S_0 & A & B\\
S_\star & C & D
\end{array}
\]

Track:

\[
\Delta_{\rm belief}=C-A,
\]

\[
\Delta_{\rm plan}^{(0)}=B-A,
\]

\[
\Delta_{\rm plan}^{(\star)}=D-C,
\]

and

\[
I=(D-C)-(B-A).
\]

The most important quantity is

\[
D-C.
\]

Does planning still help once the belief is credible?

## Planner

Use a conventional trusted method:

- fantasy rollout;
- scrambled QMC;
- common random numbers;
- paired seeds;
- standard posterior updates.

Do not use BridgeBO, path-space SMC, diffusion planning, or a new EBM sampler in this gate.

## Primary setting

Use the most informative measured protein landscape from 05A.

Freeze the exact sequential budget and fantasy budget in `SPEC.md` before the full run.

## Primary GO criterion

Pass if, using S*, \(H>1\) improves over \(H=1\) by at least one of:

- **>=15% relative reduction** in final normalized regret;
- **>=15 percentage-point increase** in a predefined target-hit probability;

with paired improvement in at least 7/10 seeds.

---

## Single prespecified fallback

If the primary test fails, run **exactly one** fallback:

### Dynamic/path-dependent experimental setting

Introduce a genuine route dependence such as

\[
c(x_t,x_{t+1})
=
d_H(x_t,x_{t+1})
\]

or a mutation-radius/action constraint corresponding to a sequential editing campaign.

Do not introduce additional fallback benchmarks after seeing this result.

## Final Gate 05C

### PASS

Pass if either:

- the original setting; or
- the single prespecified dynamic-cost setting

shows a meaningful non-myopic advantage using S*.

### FAIL

If both fail:

- kill the path-space branch;
- do not implement 06A;
- set `HUMAN_REVIEW_REQUIRED`.

At that point assess whether 05B itself produced a sufficiently strong and genuinely novel structured-decision result.

If not, return to research-selection mode rather than forcing the path paper.

# 11. Task 06A — Path-Inference Kill Test

## Authorization

Requires:

```text
05C = PASS
```

## Question

> Given a demonstrated non-myopic opportunity, does energy/path-space inference compute the relevant first-action decision better than strong rollout/tree inference at matched computational cost?

## Causal future

Let

\[
\tau
=
(x_0,y_0,\ldots,x_{H-1},y_{H-1}).
\]

Define

\[
P_0(f,\tau\mid D)
=
p_B(f\mid D)
\nu(x_0\mid D)
p(y_0\mid f,x_0)
\prod_{h=1}^{H-1}
\pi(x_h\mid D_h)
p(y_h\mid f,x_h).
\]

For terminal utility,

\[
\Pi_H(f,\tau\mid D)
\propto
P_0(f,\tau\mid D)
U_H(f,\tau).
\]

Then

\[
\boxed{
\Pi_H(x_0=x\mid D)
\propto
\nu(x\mid D)
\alpha_H^\pi(x;D).
}
\]

For uniform \(\nu\),

\[
\arg\max_x\Pi_H(x_0=x\mid D)
=
\arg\max_x\alpha_H^\pi(x;D).
\]

At \(H=1\), with a GP and improvement utility, recover EI.

## Free-energy recursion

Let

\[
Z_h(D_h)
=
\mathbb E[U_H\mid D_h]
\]

and

\[
F_h=-\log Z_h.
\]

Then

\[
\boxed{
F_h(D_h)
=
-\log
\mathbb E_{\pi,p}
\left[
e^{-F_{h+1}(D_{h+1})}
\mid D_h
\right].
}
\]

## Inference

Use established machinery first:

- SMC;
- adaptive multilevel splitting;
- subset simulation;
- another standard path sampler justified by the specific task.

Do not invent a new particle mover unless existing methods fail for a clearly diagnosed reason.

## Required baselines

At matched fantasy/path evaluations:

1. scrambled-QMC rollout;
2. QMC + common random numbers;
3. QMC/racing where applicable;
4. one-shot multi-step tree where feasible;
5. path-space energy inference.

## Primary metrics

- first-action value error against a high-precision reference;
- selected-action regret;
- reference-optimal first-action recovery.

Secondary:

- wall-clock;
- ESS;
- path-mode coverage;
- number of fantasy/path evaluations.

## Gate 06A

Proceed only if path inference gives approximately:

- **>=2x reduction** in first-action decision error at matched fantasy/path cost,

and this improvement materially reduces selected-action regret.

If QMC/racing is essentially as good:

- mark `FAIL`;
- treat path-space as a useful interpretation only;
- do not implement 06B;
- request human review.

# 12. Task 06B — Paper-Scale Validation

## Authorization

Requires:

```text
06A = PASS
```

## Objective

Demonstrate that the full formulation improves sequential decision quality rather than only providing cleaner sampler diagnostics.

## Required experimental groups

### Experiment 1 — Belief quality

Measured protein data:

\[
\text{generic belief}
\rightarrow
\text{structured belief}.
\]

Demonstrate both calibration and BO decision effects.

### Experiment 2 — Structured composition

Use a pretrained structured generator.

Show that the same Bayesian/free-energy target can be used at test time without fitting a new monolithic model.

Do not overclaim novelty for this component.

### Experiment 3 — Belief × planning

Present the \(2\times2\):

\[
S_0/S_\star
\times
H=1/H>1.
\]

This should demonstrate whether belief quality and planning quality address distinct errors.

### Experiment 4 — Main path-space capability

Compare:

- strong belief + myopic BO;
- strong belief + strongest conventional non-myopic baseline;
- strong belief + path-space energy inference.

Primary outcome:

> **actual sequential decision performance**

rather than ESS, likelihood, or sampler efficiency.

## Real-data requirement

At least one main result must query actual measured labels.

A learned proxy oracle can support a larger semi-synthetic generative experiment, but it must be labeled clearly.

## Submission-level condition

The full paper is compelling only if all hold:

1. free-energy/composition mathematics is exact and clean;
2. at least one belief is credibly calibrated and useful;
3. nonmyopia remains useful with that belief;
4. path-energy inference beats strong conventional planning at matched cost;
5. this translates into meaningful sequential decision gains;
6. at least one major result uses actual measured labels.

If 3–5 fail, do not write the paper as though the complete hypothesis succeeded.

# 13. Planned Paper Outline

## 1. Introduction

Modern BO increasingly combines:

- sparse experimental measurements;
- pretrained structured models;
- heterogeneous information or constraints;
- complex future utilities.

These components are often handled with separate bespoke methods.

Main perspective:

> **BO can instead be formulated as compositional inference over high-utility worlds.**

Do not claim that EBMs replace all GP surrogates.

## 2. BO as Free-Energy Inference

Introduce:

- belief energy;
- utility factor;
- partition-function ratio;
- GP + EI special case.

## 3. Composable Decision Factors

Introduce:

\[
E_{\rm belief}
+
E_{\rm structure}
+
E_{\rm information}
+
E_{\rm decision}.
\]

Emphasize:

- semantic scaling;
- proposal versus prior;
- sensitivity identity.

## 4. Belief Quality and Decision Quality

Introduce:

\[
\epsilon_B
+
\epsilon_I
\]

view of decision error.

Use the structured-surrogate experiment to show why both sides matter.

## 5. Structured Test-Time Inference

Show how pretrained structured models can be reused rather than retrained into a monolithic BO model.

## 6. Adaptive Futures as Path-Space Free Energy

Make this central only if Task 06A passes.

Include:

- causal fantasy path;
- first-action marginal;
- \(H=1\rightarrow EI\);
- free-energy recursion;
- established path inference.

## 7. Experiments

1. Structured belief audit.
2. Structured composition.
3. Belief × horizon.
4. Path-space capability.

## 8. Limitations

Explicitly state:

- energy composition cannot rescue a bad belief;
- semantic design priors change the decision problem;
- arbitrary temperatures alter semantics;
- samplers can miss modes;
- nonmyopia matters only when a genuine planning opportunity exists.

# 14. Execution Discipline

## Randomness

Where possible, all methods share:

- initial observations;
- train/test splits;
- BO seeds;
- fantasy randomness.

Favor paired comparisons.

## Hyperparameters

Use published/default settings whenever practical.

If tuning is required:

- use separate calibration data/seeds;
- freeze values before the full gate run;
- never tune using final BO performance.

## Statistical reporting

Prefer:

- paired effect sizes;
- confidence intervals;
- paired win counts.

Avoid a large collection of disconnected hypothesis tests.

## Runtime

Target:

- local smoke: <10 minutes;
- preflight: short enough for interactive development;
- full A100 shard: approximately <=2–3 hours;
- experiments separable by seed.

## Reproducibility

Every run records:

- Git SHA;
- configuration;
- random seed;
- device;
- runtime;
- per-iteration metrics;
- checkpoint path.
