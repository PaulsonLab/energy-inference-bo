# Closed project handoffs

This directory contains completed one-off implementation and gate handoffs.
They are retained for exact scientific provenance and are not active planning
documents. The handoffs were moved without content changes, so paths and status
language inside them describe the repository at the time of the corresponding
preregistration or run.

- [`INFERENCE_CERTIFICATION_IMPLEMENTATION_HANDOFF.md`](INFERENCE_CERTIFICATION_IMPLEMENTATION_HANDOFF.md):
  completed finite-grid inference-certification implementation contract.
- [`e3/`](e3/): closed synthetic preference and Gp2 E3 handoffs. Gp2 is
  abandoned as E3; these files are historical records, not an active plan.

Use [`../PROJECT_HANDOFF.md`](../PROJECT_HANDOFF.md) for current project status
and [`../EXPERIMENTS.md`](../EXPERIMENTS.md) for current empirical status.
